01 · The flow

Five steps, in order — because job search actually happens in order.

Each stage feeds the next (aka this is how you actually do it!).

01

Upload a persona

Drop in a resume. It's extracted, chunked, and embedded locally — this becomes the baseline every job gets scored against.

pypdf → semantic chunking → nomic-embed-text
02

Find/Add a job posting

Paste the listing, and boilerplate — nav menus, cookie banners — gets stripped automatically. Or add one through the import option (requires API key)

paste-and-clean ingestion + easy job searching
03

Read the score, not just the number

The Battle Room breaks the fit score into explicit matches and gaps, grounded in cosine similarity between your resume and the posting.

vector similarity + LLM explainability
04

Generate, then edit

A tailored resume bullet and a first-draft outreach message, written from your actual resume content — both fully editable before you use them anywhere.

bullet tailoring · outreach drafting
05

Track it through to a decision

Inbox → Reviewing → Applied → Archived. Delete what you don't need. That's the whole lifecycle.

no CRM, no pipeline software
